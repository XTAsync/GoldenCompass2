# Golden Compass — Mobile Interface

A standalone HTML prototype exploring a mobile investment-app experience, including portfolio-style screens, navigation, and a dark gold-and-navy visual design.

## Run Locally

No build tools are required. Open `gc.html` in a modern browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/gc.html`.

## Scope

This repository contains a frontend prototype only. Interface elements should not be interpreted as evidence of live account services, real-money transactions, or brokerage connectivity.
